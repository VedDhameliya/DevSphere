# 🚀 DevSphere

**A Collaborative Developer Platform**

DevSphere is a collaborative platform designed to help developers organize teams, manage projects, assign tasks, share code resources, and track development activities in one place.

Our goal is to build a portfolio-quality application while learning professional software development and GitHub collaboration practices.

## 🎯 Project Objectives

- Build a collaborative developer platform.
- Practice team-based software development.
- Learn Git, GitHub, branching, pull requests, and code reviews.
- Implement automated testing and continuous integration.
- Develop maintainable, well-documented code.

## ✨ Planned Features

- User registration and login
- Personalized dashboard
- Team creation and management
- Project creation and tracking
- Task assignment and progress tracking
- CodeVault for sharing code resources
- Activity feed
- Automated testing with pytest
- Continuous integration with GitHub Actions

## 🛠️ Technology Stack

| Technology | Purpose |

| HTML | Page structure |
| CSS | Styling and layout |
| JavaScript | Client-side interactivity |
| pytest | Automated testing |

## 👥 Team

DevSphere is developed collaboratively by a team of eight students.

Team members contribute through GitHub Issues, feature branches, pull requests, code reviews, and automated testing.

## 🚧 Project Status

**Currently in development.**

Features, installation instructions, screenshots, and usage documentation will be added as the application evolves.

## 🤝 Collaboration

We welcome organized contributions from our project team.

Our development workflow will use:

1. GitHub Issues to track tasks and bugs.
2. Feature branches for individual changes.
3. Commits with meaningful messages.
4. Pull requests for proposed changes.
5. Code reviews before merging.
6. Automated tests to help maintain code quality.
